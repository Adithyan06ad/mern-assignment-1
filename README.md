## ✨ Key Features & Technical Highlights

- **Luxury Museum Aesthetic:** Deep obsidian dark mode (`#0a0c10`), champagne gold accents (`#d4af37`), and subtle glassmorphic backdrops.
- **Modern Typography:** Editorial serifs (`Playfair Display`) paired with crisp interface typography (`Plus Jakarta Sans`).
- **Interactive Lightbox:** Click any masterpiece to inspect it in full-resolution lightbox view.
- **Client-Side Auth State:** Simulated authentication using `localStorage` updates the navigation bar to display the member's name and avatar upon logging in.
- **Dynamic Catalog Controls:** Real-time search by title or artist, category movement filtering, and chronological sorting.
- **Zero Build Step:** 100% native HTML, CSS, and vanilla JavaScript—deploys cleanly on GitHub Pages or any static host.

## 🚀 How to Submit: GitHub Repo & GitHub Hosted Link

Follow these quick steps to host your assignment on GitHub:

### Step 1: Create a New GitHub Repository
1. Log into your account on [github.com](https://github.com/).
2. Click **New Repository** (green button).
3. Name your repository (e.g., `art-gallery-assignment` or `mern-assignment-1`).
4. Set visibility to **Public** and leave "Initialize with a README" unchecked.
5. Click **Create repository**.

### Step 2: Push Your Code from Terminal
Open your terminal or command prompt inside this folder (`c:\Users\Admin\Desktop\Mern Assignment`) and run:

```bash
# 1. Initialize git (if not already initialized)
git init

# 2. Stage all files
git add .

# 3. Create your first commit
git commit -m "Complete Assignment 1: Lumière Art Gallery 10-page website"

# 4. Rename default branch to main
git branch -M main

# 5. Link your GitHub repository (replace with your actual GitHub repo URL)
git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/<YOUR_REPO_NAME>.git

# 6. Push your files to GitHub
git push -u origin main
```

---

### Step 3: Enable Free GitHub Pages (Hosted Link)
1. In your GitHub repository, click on **Settings** (top tab).
2. On the left sidebar, click on **Pages**.
3. Under **Branch**, select `main` and keep the folder set to `/(root)`.
4. Click **Save**.
5. After 1 to 2 minutes, GitHub will generate your live hosted URL:
   ```
   https://<YOUR_GITHUB_USERNAME>.github.io/<YOUR_REPO_NAME>/
   ```
